# Урок 1. Установка базовых программ для Windows

## Для чего нужен этот урок

Перед началом практической работы с кодом и инфраструктурой нужно подготовить рабочее окружение на своём ПК. В этом уроке собраны пять инструментов, которые образуют базовый набор разработчика:

- **KeePassXC** — безопасное хранение паролей и секретов (логины, токены, ключи доступа), чтобы не держать их в открытом виде.
- **Git** — система контроля версий, нужна для сохранения истории изменений кода и совместной работы с репозиториями.
- **Podman** — запуск приложений в контейнерах без необходимости поднимать полноценный Docker Desktop.
- **Visual Studio Code** — основной редактор кода для написания и отладки проектов.
- **.NET** — платформа для разработки и запуска приложений на C#/.NET.

Установка каждого инструмента описана в отдельном файле с кратким объяснением "для чего он нужен" и пошаговой инструкцией через PowerShell.

## Краткая инструкция перед началом

1. Откройте **PowerShell от имени администратора**.
2. Проверьте, что менеджер пакетов `winget` установлен:
   ```powershell
   winget --version
   ```
   Если команда не найдена — обновите "App Installer" через Microsoft Store.
3. Переходите по ссылкам ниже и устанавливайте инструменты по порядку.
4. После каждой установки проверяйте версию программы, чтобы убедиться, что всё встало корректно.

## Как переходить между директориями в PowerShell

Во время установки и дальнейшей работы (например, при создании тестового .NET-проекта) потребуется перемещаться между папками через терминал. Вот базовые команды навигации:

- **Посмотреть, в какой директории вы сейчас находитесь:**
  ```powershell
  pwd
  ```

- **Перейти в конкретную директорию по полному пути:**
  ```powershell
  cd C:\stadies\Lesons
  ```

- **Перейти во вложенную папку (относительный путь):**
  ```powershell
  cd Lessons1
  ```

- **Подняться на один уровень выше (в родительскую папку):**
  ```powershell
  cd ..
  ```

- **Перейти сразу на системный диск D, например:**
  ```powershell
  cd D:\
  ```

- **Посмотреть список файлов и папок в текущей директории:**
  ```powershell
  ls
  ```

### Пример

```powershell
cd C:\stadies\Lesons\Lessons1
ls
```

Эта команда переведёт вас в папку `Lessons1` внутри `C:\stadies\Lesons` и покажет список файлов в ней.
