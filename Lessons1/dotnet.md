# .NET

## Для чего нужен

.NET — кроссплатформенная платформа от Microsoft для разработки и запуска приложений (консольных, веб, десктопных) на языках C#, F# и других. Нужна для компиляции, запуска и тестирования .NET-проектов, которые будут использоваться в практических заданиях курса.

## Короткая инструкция по установке

1. Откройте PowerShell от имени администратора.
2. Выполните команду (замените `<ВЕРСИЯ>` на нужный номер SDK, например `8` или `9`):
   ```powershell
   winget install --id Microsoft.DotNet.SDK.<ВЕРСИЯ> -e
   ```
3. Перезапустите PowerShell.
4. Проверьте версию:
   ```powershell
   dotnet --version
   ```
5. Создайте тестовый проект, чтобы убедиться в работоспособности:
   ```powershell
   dotnet new console -o TestApp
   cd TestApp
   dotnet run
   ```
