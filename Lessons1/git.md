# Git

## Для чего нужен

Git — распределённая система контроля версий. Она позволяет отслеживать историю изменений в коде, откатываться к предыдущим версиям, работать в команде через ветки и загружать/скачивать код из удалённых репозиториев (GitHub, GitLab и т.п.). Без Git невозможна современная разработка и совместная работа над проектами.

## Короткая инструкция по установке

1. Откройте PowerShell от имени администратора.
2. Выполните команду:
   ```powershell
   winget install --id Git.Git -e
   ```
3. Перезапустите PowerShell, чтобы обновились переменные среды.
4. Проверьте версию:
   ```powershell
   git --version
   ```
5. Настройте базовые данные пользователя:
   ```powershell
   git config --global user.name "Ваше Имя"
   git config --global user.email "your_email@example.com"
   ```

## Регистрация на GitHub

1. Перейдите на сайт [github.com](https://github.com/signup).
2. Укажите email, придумайте имя пользователя и пароль, следуя инструкциям на сайте.
3. Подтвердите почту по ссылке из письма, которое придёт на указанный email.

## Что сохранить в KeePassXC

После регистрации сразу сохраните данные от аккаунта GitHub в менеджере паролей KeePassXC, чтобы не потерять доступ:

1. Откройте KeePassXC и вашу базу паролей.
2. Создайте новую запись (Entry), например с названием "GitHub".
3. Заполните поля:
   - **Логин/Username** — имя пользователя, указанное при регистрации на GitHub.
   - **Пароль/Password** — пароль, который вы задали при регистрации.
   - **URL** — `https://github.com`
4. Сохраните запись.

> Совет: если включена двухфакторная аутентификация (2FA) или вы используете Personal Access Token для Git-операций — их также стоит сохранить отдельными записями в KeePassXC.
