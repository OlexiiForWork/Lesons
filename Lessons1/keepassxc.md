# KeePassXC

## Для чего нужен

KeePassXC — бесплатный менеджер паролей с открытым исходным кодом. Он хранит все пароли, ключи и секреты в одной зашифрованной базе данных, защищённой мастер-паролем. Это избавляет от необходимости запоминать десятки паролей и хранить их в открытом виде (например, в текстовых файлах).

Пригодится для хранения учётных данных от Git-репозиториев, облачных сервисов, баз данных и прочих сервисов, с которыми вы будете работать в последующих уроках.

## Короткая инструкция по установке

1. Откройте PowerShell от имени администратора.
2. Выполните команду:
   ```powershell
   winget install --id KeePassXCTeam.KeePassXC -e
   ```
3. Проверьте, что программа установлена:
   ```powershell
   winget list --id KeePassXCTeam.KeePassXC
   ```
4. Запустите KeePassXC из меню "Пуск" и создайте новую базу данных с мастер-паролем.
