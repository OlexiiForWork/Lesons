# Podman

## Для чего нужен

Podman — инструмент для запуска и управления контейнерами, аналог Docker, но без постоянно работающего фонового демона и без необходимости устанавливать Docker Desktop. Контейнеры позволяют запускать приложения и их зависимости в изолированной, переносимой среде — это упрощает разработку, тестирование и развёртывание приложений.

**Podman Desktop** — графическое приложение для управления Podman: контейнерами, образами, виртуальными машинами. Оно удобнее для начала работы, чем чистая командная строка, и при первом запуске само помогает установить движок Podman.

## Как проверить разрядность системы

Перед установкой убедитесь, какая у вас версия Windows — 32-bit (x86) или 64-bit (x64).

```powershell
[Environment]::Is64BitOperatingSystem
```

- Если результат `True` — у вас 64-битная система, можно продолжать установку (см. ниже).
- Если результат `False` — у вас 32-битная система. **Podman и Podman Desktop на 32-bit Windows не работают и не поддерживаются.** Podman использует WSL2 или Hyper-V для запуска Linux-контейнеров, а обе эти технологии требуют 64-битную систему. На 32-bit Windows установить и использовать Podman невозможно — нужен переход на 64-bit систему или альтернативный инструмент.

## Короткая инструкция по установке

1. Откройте PowerShell от имени администратора.
2. Выполните команду:
   ```powershell
   winget install --id RedHat.Podman-Desktop -e
   ```
3. Запустите **Podman Desktop** из меню "Пуск".
4. При первом запуске приложение предложит установить движок Podman (CLI) — согласитесь и дождитесь завершения установки.
5. Проверьте версию CLI в PowerShell:
   ```powershell
   podman --version
   ```

## Инструкция по запуску

1. Инициализируйте виртуальную машину Podman (выполняется один раз, если не было сделано автоматически через Podman Desktop):
   ```powershell
   podman machine init
   ```
2. Запустите машину:
   ```powershell
   podman machine start
   ```
3. Проверьте статус машины:
   ```powershell
   podman machine list
   ```
4. Запустите тестовый контейнер, чтобы убедиться, что всё работает:
   ```powershell
   podman run hello-world
   ```
5. Чтобы остановить машину после работы:
   ```powershell
   podman machine stop
   ```

> Все эти же действия (запуск, остановка, список контейнеров) можно выполнять через графический интерфейс Podman Desktop без использования терминала.
