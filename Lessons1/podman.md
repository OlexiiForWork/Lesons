# Podman

## Для чего нужен

Podman — инструмент для запуска и управления контейнерами, аналог Docker, но без постоянно работающего фонового демона и без необходимости устанавливать Docker Desktop. Контейнеры позволяют запускать приложения и их зависимости в изолированной, переносимой среде — это упрощает разработку, тестирование и развёртывание приложений.

## Как проверить разрядность системы

Перед установкой убедитесь, какая у вас версия Windows — 32-bit (x86) или 64-bit (x64).

```powershell
[Environment]::Is64BitOperatingSystem
```

- Если результат `True` — у вас 64-битная система, можно продолжать установку (см. ниже).
- Если результат `False` — у вас 32-битная система. **Podman на 32-bit Windows не работает и не поддерживается.** Podman использует WSL2 или Hyper-V для запуска Linux-контейнеров, а обе эти технологии требуют 64-битную систему. На 32-bit Windows установить и использовать Podman невозможно — нужен переход на 64-bit систему или альтернативный инструмент.

## Короткая инструкция по установке

1. Откройте PowerShell от имени администратора.
2. Выполните команду:
   ```powershell
   winget install --id RedHat.Podman -e
   ```
3. Проверьте версию:
   ```powershell
   podman --version
   ```

## Инструкция по запуску

1. Инициализируйте виртуальную машину Podman (выполняется один раз):
   ```powershell
   podman machine init
   ```
2. Запустите машину:
   ```powershell
   podman machine start
   ```
3. Проверьте статус машины:
   ```powershell
   podman machine list
   ```
4. Запустите тестовый контейнер, чтобы убедиться, что всё работает:
   ```powershell
   podman run hello-world
   ```
5. Чтобы остановить машину после работы:
   ```powershell
   podman machine stop
   ```
