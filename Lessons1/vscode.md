
# Visual Studio Code

## Для чего нужен

Visual Studio Code (VS Code) — бесплатный, легковесный и расширяемый редактор кода от Microsoft. Поддерживает множество языков программирования через расширения, встроенный терминал, интеграцию с Git и отладчик. Это основной инструмент для написания, редактирования и отладки кода во всех последующих уроках.

## Как проверить разрядность системы

Перед установкой убедитесь, какая у вас версия Windows — 32-bit (x86) или 64-bit (x64), так как от этого зависит, какую версию VS Code ставить.

```powershell
[Environment]::Is64BitOperatingSystem
```

- Если результат `True` — у вас 64-битная система, устанавливайте актуальную версию VS Code через `winget` (см. ниже).
- Если результат `False` — у вас 32-битная система. Начиная с версии **1.84** VS Code больше **не поддерживает** 32-битную Windows. Последняя поддерживаемая версия — **1.83**, её нужно скачивать вручную со страницы старых релизов VS Code, `winget` установит актуальную 64-bit сборку, которая не запустится.

## Короткая инструкция по установке

1. Откройте PowerShell от имени администратора.
2. Выполните команду:
   ```powershell
   winget install --id Microsoft.VisualStudioCode -e
   ```
3. Перезапустите PowerShell.
4. Проверьте версию:
   ```powershell
   code --version
   ```
5. Запустите редактор командой:
   ```powershell
   code .
   ```
