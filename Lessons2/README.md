# Урок 2. Клонирование репозитория ONIX

## Цель урока

В этом уроке вы скачаете копию репозитория ONIX на свой компьютер с помощью Git.

## Перед началом

Убедитесь, что Git установлен. Откройте PowerShell и проверьте его версию:

```powershell
git --version
```

Если команда не найдена, сначала установите Git по инструкции из [урока 1](../Lessons1/git.md).

## Последовательность команд

1. Создайте папку для учебных репозиториев и перейдите в неё:

   ```powershell
	  New-Item -ItemType Directory -Force "C:\Stading"
   cd "C:\Stading"
   ```

2. Склонируйте репозиторий ONIX:

   ```powershell
   git clone https://github.com/OlexiiForWork/ONIX.git
   ```

   Git создаст в текущей папке каталог `ONIX` и загрузит в него репозиторий.

3. Перейдите в каталог репозитория и проверьте его состояние:

   ```powershell
   cd ONIX
   git status
   ```

4. Посмотрите содержимое каталога:

   ```powershell
   Get-ChildItem
   ```

## Итог

Репозиторий находится в папке `C:\Stading\ONIX`. Чтобы вернуться к работе с ним в следующий раз, откройте PowerShell и выполните:

```powershell
cd "C:\Stading\ONIX"
```
