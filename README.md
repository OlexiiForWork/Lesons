# Lessons

Репозиторий с конспектами и практическими занятиями по настройке рабочего окружения разработчика и базовым DevOps-инструментам.

## О проекте

Здесь собраны материалы курса/серии уроков, посвящённых установке и настройке основных инструментов разработчика на Windows: менеджер паролей, система контроля версий, контейнеризация, редактор кода и платформа .NET.

## Структура

- [Lessons1](./Lessons1/README.md) — Урок 1. Установка базовых программ для Windows (KeePassXC, Git, Podman, Visual Studio Code, .NET)

## Технологии и инструменты

- Windows PowerShell
- KeePassXC
- Git
- Podman
- Visual Studio Code
- .NET

## Как использовать

Открывайте уроки по порядку, начиная с `Lessons1`. Каждый урок содержит пошаговые инструкции и команды для PowerShell.
